# UniTime для iOS

iOS-версия [UniTime](https://github.com/molex1le/UniTime): расписание БГУИР, следующая пара на экране блокировки, виджеты, дедлайны, общие окна с друзьями и личный кабинет IIS.

Написано на Swift и SwiftUI с нуля, логика перенесена из Android-версии один к одному. Требуется iOS 17 или новее.

## Установка через iLoader

1. Открой вкладку [Actions](../../actions) этого репозитория, выбери последний зелёный запуск **iOS** и скачай артефакт **UniTime-ipa** (внутри лежит `UniTime.ipa`). Если есть [релизы](../../releases), можно скачать `UniTime.ipa` прямо оттуда.
2. Подключи iPhone к компьютеру, открой iLoader, войди своим Apple ID и установи `UniTime.ipa`.
3. На iPhone: **Настройки → Основные → VPN и управление устройством** → доверься своему Apple ID. На iOS 16+ ещё нужен **Режим разработчика** (Настройки → Конфиденциальность и безопасность).
4. С бесплатным Apple ID приложение работает 7 дней, потом его нужно переподписать в iLoader. Данные при этом сохраняются.

## Что умеет

- **Расписание**: «Сегодня» с главной карточкой, лента «Пары» до конца семестра, номера недель, подгруппы, скрытые пары, перемены и окна, поиск групп и преподавателей с фото, сессия.
- **Экран блокировки**: Live Activity с текущей или следующей парой и отсчётом времени (в том числе в Dynamic Island), виджет «Следующая пара» для экрана блокировки.
- **Виджеты**: следующая пара (маленький и средний), пары на день, дедлайны, дни до сессии. Светлая и тёмная тема переключаются вместе с системой.
- **Дедлайны**: срок «к следующей паре» в одно нажатие, напоминания за сутки и за 2 часа.
- **Друзья**: где сейчас друг и когда у вас общие окна.
- **Личный кабинет IIS**: зачётка, успеваемость, пропуски, деканат, общежитие, группа, библиотека, уведомления. Фоновая проверка новых оценок и пропусков.
- **Ещё**: темы «Авто», «Светлая», «Чёрная» и секретный «Неон», стили «Обычный», «Стекло» и «Цвет пар», экспорт пар в календарь iPhone, уведомления об изменениях в расписании.

## Отличия от Android

| Android | iOS |
|---|---|
| Постоянное уведомление со следующей парой | Live Activity и виджет на экране блокировки |
| Проверки по будильнику в точное время | Фоновое обновление iOS: система сама решает когда, поэтому уведомления о новых оценках могут приходить с задержкой. При открытии приложения всё обновляется сразу |
| Обновление APK внутри приложения | Приложение сообщает о новой версии, ставить её нужно заново через iLoader |
| Запись в Google Календарь | Отдельный календарь «UniTime» на iPhone, удаляется одной кнопкой |

## Для разработчиков

Проект описан в `project.yml` для [XcodeGen](https://github.com/yonaskolb/XcodeGen):

```bash
brew install xcodegen
xcodegen generate
open UniTime.xcodeproj
```

- `Shared/` — общий код приложения и виджетов: даты, разбор JSON, расписание, хранилище (App Group), форматирование.
- `UniTime/` — приложение: экраны, кабинет IIS, уведомления, Live Activity, фоновое обновление, календарь.
- `Widgets/` — расширение WidgetKit: виджеты и Live Activity.
- `Tests/` — тесты логики расписания, запускаются без Xcode: `swiftc Shared/{Time,JSON,Schedule,Format,Stats,Store}.swift Tests/main.swift -o t && ./t`.

GitHub Actions (`.github/workflows/ios.yml`) на каждом пуше прогоняет тесты, собирает неподписанный `UniTime.ipa` и прикладывает его как артефакт. Релиз с IPA создаётся любым из способов:

- пуш тега `v*`: `git tag v1.1 && git push origin v1.1`;
- коммит, в сообщении которого есть `[release v1.1]`;
- ручной запуск workflow **iOS** во вкладке Actions с заполненным полем `release`.

Текст релиза берётся из `.github/release-notes.md`.

## Приватность

- Расписание берётся из открытого API `iis.bsuir.by`, своих серверов нет.
- Логин и пароль IIS отправляются только на `iis.bsuir.by`. Если включить «Запомнить пароль», он хранится в связке ключей iOS. «Выйти» стирает всё.
- Ни аналитики, ни рекламы.
